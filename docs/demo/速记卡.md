# 速记卡 —— 一页纸，上台前扫一遍

> 2026-09-06，main `f7222f9`。数字来自 README 与 `eval_reports/latest_v3-policy.md`、ADR-0007 附录。

## 一句话

模型只负责听懂和提议，判定、执行、记账全部交给确定性代码。

## 三条红线

1. 身份与授权永不经过 LLM（工具签名无 user_id）
2. 写操作永不由 LLM 直接触发（提议 → 策略引擎 → 用户确认 → 幂等键）
3. 记忆永不进入授权与策略判断（判定输入类型里没有 memory 字段，10 条投毒测试）
