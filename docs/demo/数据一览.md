## 怎么自己查

```bash
make psql
```

进去后常用：

```sql
\dt biz.*                                   -- 业务表
\dt agent.*                                 -- agent 侧表
select * from biz.orders where user_id=101; -- 某人的订单
select * from agent.user_memory where user_id=101 and deleted_at is null;  -- 长期记忆
select thread_id, case_facts from agent.case_state order by updated_at desc limit 3;  -- 案件事实
select * from agent.audit_log order by id desc limit 10;  -- 审计
```

图形界面（TablePlus / DBeaver / pgAdmin）连接串在仓库根 `.env` 的 `DATABASE_URL`。
