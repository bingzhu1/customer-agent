## 3. 一句话讲清技术栈

LangGraph 状态图（ingest → understand → act → policy_gate → decide → respond → persist），Anthropic 主模型 claude-sonnet-5，抽取用 claude-haiku-4-5；FastAPI + JWT；PostgreSQL 16 + pgvector（HNSW）；OpenAI text-embedding-3-small；SQLAlchemy Repository 强制 scope；策略引擎与决策矩阵是纯 Python 函数。
